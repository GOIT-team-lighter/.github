## 🇬🇧 English

<details open>
<summary><b>About us & how we work</b></summary>

<br/>

**📌 About us**

We are a team of three GoIT students learning on a real full-stack project: a backend API and a frontend client living side by side in two separate repositories. Everyone writes code, and each of us also owns an area: technical leadership, project organization, or QA and automation.

**🛠️ How we work**

- 🌿 **Branches:** `main` is protected - work happens in dedicated `feature/*` and `fix/*` branches.
- 🔍 **Code review:** every change reaches `main` only through a pull request with at least one approval from a real human.
- 📋 **Tasks:** tracked on our GitHub Projects board.
- ✅ **Quality:** linting and tests run automatically on every pull request.

</details>

## 🇺🇦 Українська

<br/>

**📌 Про нас**

Ми - команда з трьох студентів GoIT, яка навчається на реальному full-stack проєкті: серверне API та клієнтський застосунок живуть поруч у двох різних репозиторіях. Кодять усі, а крім того кожен відповідає за свій напрям: технічне лідерство, організацію роботи або QA та автоматизацію.

**🛠️ Як ми працюємо**

- 🌿 **Гілки:** `main` захищена - робота ведеться в спеціалізованих гілках `feature/*` та `fix/*`.
- 🔍 **Code review:** кожна зміна потрапляє в `main` лише через pull request з щонайменше одним апрувом людини живої людини.
- 📋 **Задачі:** ведемо на дошці GitHub Projects.
- ✅ **Якість:** лінтер і тести автоматично запускаються на кожен pull request.

</details>
